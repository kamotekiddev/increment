# Roadmap

Six phases, about 18 weeks, for one full-time developer. The weeks are estimates; each phase ends at a gate, and the next phase starts only when its gate is met. Full plan: https://claude.ai/artifact/3kxR4KCu53v3WBdmfm99Gc

| Phase | Weeks | Focus | Gate |
|---|---|---|---|
| 0 · Foundations | 1–2 | Project, theme, base components, database, overload engine and conversion with tests, library data | The app opens on both phones; the engine passes every rule |
| 1 · Core training loop | 3–6 | Library, routines, live workout, rest timer, free rule, summary, Today, crash resume | A full week of your own workouts logged in the app, with every target correct |
| 2 · Progress, units, settings | 7–9 | Records, exercise history, kg/lb, the Jump per equipment, workout settings, reminders | Switching units never changes stored data; every target is loadable |
| 3 · Pro | 10–13 | Purchase and restore, paywall, limit pop-up, rule panel, custom exercises, charts, backups, auto backups, export, plate calculator (a separate function from the engine), delete all | Pro unlocks offline on both stores; a backup restores on a new phone |
| 4 · Onboarding and polish | 14–15 | Questions, plan generator, quick start, restore path, accessibility, haptics, icon and store art | Install to first logged set in under 3 minutes |
| 5 · Beta and launch | 16–18 | TestFlight and Play beta (15–30 lifters), fixes, privacy labels, store listings, review | Two weeks of beta with no lost workouts or purchase failures, then store approval |

## After launch
