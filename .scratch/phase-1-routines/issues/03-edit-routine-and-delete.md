# 03: Edit routine, rename, days and delete

**What to build:** Edit routine shows the name, day buttons and exercise rows. The name saves when the lifter finishes and shows an inline error if invalid; leaving with an invalid name restores the saved one. Day buttons save at once. ⋯ → Delete routine confirms with the number of workouts that will be deleted, then deletes the routine, its exercises and its workouts. A Drizzle migration makes `workouts.routine_id` cascade.
