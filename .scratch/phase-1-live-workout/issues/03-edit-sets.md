# 03: Edit sets: type, −/+, follow rule, Add set, Last column

**What to build:** On the live workout, the lifter can type weight and reps, nudge weight with − and + by the Jump, and add a set beyond the plan. Untouched rows below an edit follow it. A read-only Last column shows the same set from the last finished workout of this routine exercise.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Typing a weight or reps saves at once
- [ ] − and + move the weight by the Jump
- [ ] Rows follow an edit only if untouched and not done
- [ ] Add set adds a row copying the one above; there is no remove control
- [ ] The Last column shows the previous result per set, and "–" for an added set
